DOM_JS. Считываем информацию из DOM

На странице Паспорт с помощью инструментов разработчика браузера были получены из DOM следующие данные: фамилия, имя, отчество, год рождения.

Использованные команды:

document.getElementById('lastname').innerText
document.getElementById('firstname').innerText
document.getElementById('patronymic').innerText
document.getElementById('birth').innerText
